# مول التوصيل 3D — LIVREUR RUSH: MOROCCO

لعبة توصيل ثلاثية الأبعاد مستوحاة من أجواء المدن المغربية. الواجهة بالعربية RTL، مبنية بـ Three.js وVite، وتدعم الحاسوب والهاتف.

## المتطلبات
- Node.js 18 أو أحدث
- npm

## تشغيل اللعبة
```bash
npm install
npm run dev
```
افتح رابط Vite الظاهر في الطرفية (افتراضياً المنفذ 3000).

## التحكم
- W أو ↑: تسريع
- S أو ↓: فرامل
- A أو ←: يسار
- D أو →: يمين
- Space: المنبه
- E: قبول الطلب
- Esc أو P: إيقاف مؤقت
- الهاتف: أزرار اللمس الظاهرة على الشاشة

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```

## السيرفر واللعب الجماعي (اختياري)
```bash
cd server
npm install
npm start
```
السيرفر يستعمل المنفذ 3001 افتراضياً، ويمكن فحصه عبر `/health`. GitHub Pages يستضيف الواجهة فقط؛ لتشغيل Socket.IO خاصك تستضيف السيرفر على خدمة تدعم Node.js.

## ملاحظات
- اللعبة الفردية لا تحتاج إلى سيرفر.
- `VITE_SERVER_URL` عنوان عام للمتصفح، فلا تضع أسراراً فيه.
- بعض خيارات اللعب الجماعي في الواجهة هي واجهة أولية؛ اللعبة الفردية هي المسار المكتمل حالياً.
